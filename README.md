# VIA design drafts

VIA definitions for my keyboards: the Katana60 and the Tsuka60, including some old prototypes that have been sitting in a drawer for years.

## How to use

1. Flash the board with VIA-enabled firmware. The keyboard definitions live in my QMK fork: [rominronin/qmk_firmware](https://github.com/rominronin/qmk_firmware) (`keyboards/rominronin`).
2. Open [usevia.app](https://usevia.app), go to Settings and switch on "Show Design tab".
3. In the Design tab, load the JSON file for your board.
4. Go back to Configure. Pick your physical layout (spacebar split, backspace and so on) under Layouts.
